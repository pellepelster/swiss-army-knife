# Android

You can use SAK Notes and SAK Grocery List on an Android phone in two ways:

- **[The web apps](web-apps.md):** you install them from Chrome or Firefox in a few taps.
- **[The native apps](native-apps.md):** you download them from the GitHub release of your SAK instance.

## Apps from outside of Google Play

The native apps do not come from Google Play, and Android makes it difficult to install such an app:

- The browser, Android and Play Protect each show a warning, and some of them look like the app is dangerous.
- You must let the browser install apps, and later the app itself, so that it can install its updates.
- Each phone and each Android version shows different words, so the steps can look different on your phone.

The web apps do not have these problems. You install them without a download and without warnings, and the browser
keeps them up to date. If you do not need the native apps, [install the web apps](web-apps.md).
